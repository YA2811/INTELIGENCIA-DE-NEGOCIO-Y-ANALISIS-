# Sistema de Inteligencia de Negocios para PyMEs - Valle de Ubaté

## Descripción
Plataforma de Inteligencia de Negocios y Analítica Descriptiva/Predictiva de bajo costo orientada a PyMEs locales.

## Estructura del Repositorio
- `database/`: Scripts SQL de creación (DDL) y datos semilla (DML).
- `src/`: Pipeline de extracción (ETL) y conexión a base de datos.
- `tests/`: Pruebas unitarias sobre las reglas de negocio.
- `app.py`: Tablero de control interactivo en Streamlit.
